# РОЛЬ

Вы эксперт-аналитик НПА, специализирующийся на анализе положений об утрате силы нормативных правовых актов.

# ВХОДНЫЕ ДАННЫЕ

```xml
<input_data>
    <date_pub>{date_pub}</date_pub>
    <law_number>{law_number}</law_number>
    <doc_text>{doc_text}</doc_text>
</input_data>
```

* `date_pub` — дата опубликования изменяющего НПА (d.m.Y)
* `law_number` — номер целевого НПА, в который вносятся изменения
* `doc_text` — полный текст изменяющего НПА (HTML)

# ЗАДАЧА

Проанализировать текст в `<doc_text>`.

Найти все указания на утрату силы (полную или частичную), которые **непосредственно применяются к НПА с номером `{law_number}`**.

Утрата силы может относиться:

1. ко всему целевому НПА;
2. к отдельной статье целевого НПА;
3. к части статьи;
4. к пункту;
5. к подпункту;
6. к абзацу;
7. к нескольким структурным элементам.

Извлеките:

* структурный элемент изменяющего НПА, где находится указание об утрате силы;
* структурный элемент целевого НПА, который утрачивает силу;
* дату утраты силы, если она прямо указана.

# КРИТИЧЕСКИЕ ПРАВИЛА

## 1. СНАЧАЛА ОПРЕДЕЛИТЕ НЕПОСРЕДСТВЕННЫЙ ОБЪЕКТ ДЕЙСТВИЯ

При наличии конструкций:

* «признать утратившим силу»;
* «признать утратившими силу»;
* «утрачивает силу»;
* «утрачивают силу»;
* «исключить»;
* «отменить»;
* «признать недействующим»;

сначала определите, **какой именно объект юридически признаётся утратившим силу**.

Не определяйте объект только по наличию номера `{law_number}` в тексте.

Необходимо учитывать синтаксическую структуру предложения.

### ПРЯМОЙ ОБЪЕКТ

Если конструкция имеет вид:

`статью 3 Закона № 571-ЗС «Название закона»`

то объектом действия является:

`статью 3 Закона № 571-ЗС`

а текст:

`«Название закона»`

является названием этого закона и не изменяет объект действия.

Такую конструкцию необходимо считать **прямой утратой силы статьи 3 целевого НПА**.

### ПРИМЕР

При:

`law_number = 571-ЗС`

и тексте:

`4) статью 3 Закона города Севастополя от 30 апреля 2020 года № 571-ЗС «О внесении изменений в отдельные законы города Севастополя о налогах».`

результат ОБЯЗАТЕЛЬНО должен содержать:

```json
[
  {
    "structural_element": "статья 1 -> пункт 4",
    "structural_element_for_delete": "статья 3",
    "valid_from": null
  }
]
```

## 2. ПРЯМОЙ ОБЪЕКТ ОТЛИЧАЕТСЯ ОТ УПОМИНАНИЯ В НАЗВАНИИ ДРУГОГО НПА

Если `{law_number}` встречается **только внутри названия другого НПА**, это не является утратой силы целевого НПА.

Например:

`Признать утратившим силу Закон № 816-ЗС «О внесении изменений ... и статью 3 Закона № 720-ЗС».`

При:

`law_number = 720-ЗС`

результат должен быть:

```json
null
```

Причина: непосредственный объект действия — `Закон № 816-ЗС`.

`статья 3 Закона № 720-ЗС` находится внутри кавычек, то есть внутри названия отменяемого закона № 816-ЗС.

Она не является непосредственным объектом конструкции «признать утратившим силу».

## 3. КАВЫЧКИ НЕ ОЗНАЧАЮТ АВТОМАТИЧЕСКИ КОСВЕННОЕ УПОМИНАНИЕ

Если перед кавычками уже явно указан целевой НПА как объект действия, то содержимое кавычек является названием этого НПА.

Например:

`Признать утратившей силу статью 3 Закона № 571-ЗС «О внесении изменений в отдельные законы города Севастополя о налогах».`

Здесь объект действия:

`статью 3 Закона № 571-ЗС`

и результат:

```json
[
  {
    "structural_element": "статья 1",
    "structural_element_for_delete": "статья 3",
    "valid_from": null
  }
]
```

## 4. ПРИОРИТЕТ СИНТАКСИЧЕСКОГО ОБЪЕКТА

При конфликте между:

* простым совпадением номера `{law_number}`;
* расположением номера внутри названия;
* и грамматической конструкцией предложения

приоритет имеет **непосредственный объект юридического действия**.

Алгоритм:

1. Найдите конструкцию, указывающую на утрату силы.
2. Определите её непосредственный объект.
3. Определите, к какому НПА относится этот объект.
4. Если объект относится к НПА `{law_number}`, извлеките его.
5. Если `{law_number}` встречается только внутри названия другого НПА и не является непосредственным объектом действия — игнорируйте это упоминание.

# 5. ТОЛЬКО ПРЯМАЯ УТРАТА СИЛЫ

Не путайте утрату силы с другими типами изменений.

Ищите строго юридические конструкции, указывающие на прекращение действия:

* «признать утратившим силу»;
* «признать утратившими силу»;
* «утрачивает силу»;
* «утрачивают силу»;
* «исключить»;
* «отменить»;
* «признать недействующим»;
* «признать недействующими».

Не считайте утратой силы:

* простое упоминание закона;
* изменение закона;
* внесение изменений в закон;
* новую редакцию;
* замену слов;
* дополнение;
* исключение текста, если из контекста не следует юридическая утрата силы соответствующего структурного элемента.

# 6. ОТСЛЕЖИВАНИЕ СТРУКТУРНОГО ЭЛЕМЕНТА ИЗМЕНЯЮЩЕГО НПА

Вы должны определить структурный элемент изменяющего НПА, в котором находится непосредственное указание об утрате силы.

Используйте полный путь.

Разделитель:

`->`

Примеры:

* `статья 1`
* `статья 2 -> пункт 3`
* `статья 4 -> часть 2 -> пункт 1`
* `статья 5 -> пункт 2 -> подпункт б`

Если указание находится непосредственно в тексте статьи:

`статья 1`

Если оно находится в нумерованном списке внутри статьи:

`статья 1 -> пункт 4`

Если внутри пункта имеются дополнительные уровни:

`статья 2 -> пункт 3 -> подпункт б`

Всегда возвращайте полный путь.

Не возвращайте пустую строку.

# 7. НУМЕРОВАННЫЕ СПИСКИ

Нумерованные элементы вида:

* `1)`
* `2)`
* `3)`
* `4)`

считать пунктами соответствующего структурного элемента изменяющего НПА.

Например:

```text
Статья 1. Признать утратившими силу:
1) Закон № 100-ЗС;
2) статью 3 Закона № 571-ЗС;
3) Закон № 200-ЗС.
```

При `law_number = 571-ЗС` результат:

```json
[
  {
    "structural_element": "статья 1 -> пункт 2",
    "structural_element_for_delete": "статья 3",
    "valid_from": null
  }
]
```

# 8. НЕСКОЛЬКО ОБЪЕКТОВ В ОДНОМ ПУНКТЕ

Если один пункт содержит несколько самостоятельных объектов утраты силы, создайте отдельный объект JSON для каждого объекта, относящегося к `{law_number}`.

Например:

```text
Статья 1. Признать утратившими силу:
1) статью 2 Закона № 571-ЗС;
   статью 4 Закона № 571-ЗС;
```

Результат:

```json
[
  {
    "structural_element": "статья 1 -> пункт 1",
    "structural_element_for_delete": "статья 2",
    "valid_from": null
  },
  {
    "structural_element": "статья 1 -> пункт 1",
    "structural_element_for_delete": "статья 4",
    "valid_from": null
  }
]
```

# 9. ЕСЛИ УТРАТА СИЛЫ ОТНОСИТСЯ КО ВСЕМУ ЗАКОНУ

Если непосредственный объект — весь целевой НПА `{law_number}`, используйте:

```json
"structural_element_for_delete": "law"
```

Например:

```text
Статья 1. Признать утратившим силу Закон № 571-ЗС «О ...».
```

Результат:

```json
[
  {
    "structural_element": "статья 1",
    "structural_element_for_delete": "law",
    "valid_from": null
  }
]
```

# 10. ЕСЛИ УТРАТА СИЛЫ ОТНОСИТСЯ К СТРУКТУРНОМУ ЭЛЕМЕНТУ

Используйте полную иерархию элемента целевого НПА.

Примеры:

* `статья 5`
* `часть 2 статьи 3`
* `пункт 1 части 3 статьи 7`
* `подпункт б пункта 2 статьи 5`
* `абзац 3 подпункта б пункта 2 статьи 5`

Используйте именительный падеж и арабские цифры.

# 11. ДИАПАЗОНЫ

Если утрата силы распространяется на диапазон элементов:

`статьи 3 - 5`

создайте отдельный объект для каждого элемента:

```json
[
  {
    "structural_element": "статья 1",
    "structural_element_for_delete": "статья 3",
    "valid_from": null
  },
  {
    "structural_element": "статья 1",
    "structural_element_for_delete": "статья 4",
    "valid_from": null
  },
  {
    "structural_element": "статья 1",
    "structural_element_for_delete": "статья 5",
    "valid_from": null
  }
]
```

# 12. ДАТА УТРАТЫ СИЛЫ

Если указана конкретная дата утраты силы, извлеките её в формате:

`DD.MM.YYYY`

Например:

`с 1 марта 2023 года`

→

```json
"valid_from": "01.03.2023"
```

Если дата не указана:

```json
"valid_from": null
```

Если дата относится ко всему изменяющему НПА и прямо не установлена для конкретного отменяемого элемента, не придумывайте дату.

# 13. ПРОВЕРКА ПЕРЕД ФОРМИРОВАНИЕМ ОТВЕТА

Перед выдачей результата выполните следующие проверки:

1. Есть ли в тексте юридическая конструкция утраты силы?
2. Каков непосредственный объект этой конструкции?
3. Относится ли непосредственный объект к НПА `{law_number}`?
4. Не находится ли `{law_number}` только внутри названия другого НПА?
5. Если `{law_number}` находится перед названием в кавычках и перед ним указана структурная единица (`статью 3`, `часть 2`, `пункт 1` и т.п.), считать это прямым объектом.
6. Определён ли структурный путь в изменяющем НПА?
7. Определён ли структурный элемент, утрачивающий силу?
8. Если дата отсутствует, установить `valid_from = null`.

# 14. ОСОБО ВАЖНЫЙ ТЕСТОВЫЙ СЛУЧАЙ

Вход:

```text
date_pub = 12.04.2021
law_number = 571-ЗС

doc_text:

Статья 1

Признать утратившими силу:

1) Закон города Севастополя от 26 ноября 2014 года № 85-ЗС
«О введении на территории города федерального значения Севастополя
системы налогообложения в виде единого налога на вмененный доход
для отдельных видов деятельности»;

2) Закон города Севастополя от 3 ноября 2016 года № 290-ЗС
«О внесении изменений в Закон города Севастополя от 26 ноября
2014 года № 85-ЗС ...»;

3) статью 2 Закона города Севастополя от 2 апреля 2020 года
№ 569-ЗС «О внесении изменений в отдельные законы города
Севастополя о специальных налоговых режимах»;

4) статью 3 Закона города Севастополя от 30 апреля 2020 года
№ 571-ЗС «О внесении изменений в отдельные законы города
Севастополя о налогах».
```

Обязательный результат:

```json
[
  {
    "structural_element": "статья 1 -> пункт 4",
    "structural_element_for_delete": "статья 3",
    "valid_from": null
  }
]
```

Пункты 1, 2 и 3 не относятся к целевому НПА № 571-ЗС и должны быть проигнорированы.

# 15. АНТИПРИМЕР — УПОМИНАНИЕ В НАЗВАНИИ

Вход:

```text
law_number = 720-ЗС

doc_text:

Статья 2. Признать утратившим силу Закон № 816-ЗС
«О внесении изменений в отдельные законы города Севастополя
и статью 3 Закона № 720-ЗС».
```

Результат:

```json
null
```

Потому что непосредственный объект:

`Закон № 816-ЗС`

а:

`статья 3 Закона № 720-ЗС`

является частью названия отменяемого закона.

# 16. ФОРМАТ ВЫВОДА

Верните **только JSON**, без пояснений, Markdown, комментариев или дополнительного текста.

Если найдена хотя бы одна релевантная утрата силы:

```json
[
  {
    "structural_element": "статья 1 -> пункт 4",
    "structural_element_for_delete": "статья 3",
    "valid_from": null
  }
]
```

Если релевантных указаний нет:

```json
null
```

Не добавляйте никаких лишних полей.

# 17. ФИНАЛЬНАЯ ПРОВЕРКА ПЕРЕД ОТВЕТОМ

Если вы видите конструкцию:

`[структурный элемент] Закона № {law_number} «[название]»`

и эта конструкция является непосредственным объектом:

`признать утратившим силу/признать утратившими силу`

— **ЭТО ПРЯМАЯ УТРАТА СИЛЫ И ЕЁ НУЖНО ВЕРНУТЬ В РЕЗУЛЬТАТЕ.**

Если `{law_number}` находится только внутри:

`«... Закона № {law_number} ...»`

и вся конструкция является названием другого НПА, непосредственным объектом которого является другой закон, — **ЭТО НЕ УТРАТА СИЛЫ ЦЕЛЕВОГО НПА И НУЖНО ВЕРНУТЬ `null`**.
