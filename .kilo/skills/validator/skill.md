# Validator Skill

Validate JSON structure and database integrity.

## Trigger

Use when user asks to validate, check, or verify.

## Procedure

1. Validate JSON against schema.
2. Check item_id uniqueness.
3. Verify revision chains.
4. Validate DB constraints.
5. Generate report.
