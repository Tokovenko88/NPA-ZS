# Database Schema

Key tables:

- `npa_base` — document passport
- `npa_item` — structural elements tree
- `npa_item_revision` — content revisions
- `npa_item_head_revision` — title revisions
- `npa_paragraph` — paragraphs within revision
- `npa_head_revision` — document title revisions
- `npa_note_unified` — unified notes
- `person`, `person_post`, `convocation`, `committees` — reference data

See `docs/db_schema.md` for full details.
